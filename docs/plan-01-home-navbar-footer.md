# خطة المرحلة 1 — الهوم + الفوتر + الناف بار

**الحالة:** في انتظار موافقتك قبل بدء أي تنفيذ فعلي في الكود.
**النطاق:** هذه المرحلة فقط — Navbar + Home Page + Footer. لا شيء غير ذلك.

---

## 0. قواعد عامة متفق عليها

- **لا تنفيذ من غير تعليمات صريحة.** أي خطوة تنفيذ لازم تيجي بأمر مباشر مني.
- **الألوان:** لسه مش موجودة — هتتحدد لاحقًا. أي مكان لونه في الخطة ده placeholder فقط لحد ما تدي الـ palette.
- **الترجمة:** كل صفحة ليها ملف ترجمة خاص بيها (عربي + إنجليزي) بدل ملف واحد عام لكل الموقع.
- **الصور:** كل الصور (بما فيها اللوجو الموجود حاليًا) في:
  `C:\Users\PC\Desktop\DTS-WEB V2\public\images`
- **المرجع التصميمي:** موقع Zapier (zapier.com) — الشكل، الـ layout، الـ logic، الأنيميشن. المحتوى الداخلي بس هو اللي هيتغير ليناسب DTS.
- **الفونت:** نفس الفونت المستخدم في Zapier (Söhne للعناوين + Inter للنصوص) + اختيار فونت عربي مناسب يتماشى معاه (مرشح: Tajawal).
- **الأيقونات:** نفس ستايل الأيقونات المستخدمة في Zapier.

## 1. هيكل صفحات الموقع كامل (للسياق فقط — التنفيذ هيتم صفحة صفحة)

| الصفحة | الرابط (anchor) | الملاحظات |
|---|---|---|
| الرئيسية | `#home` | المرحلة الحالية |
| خدماتنا | `#services` | أهم جزء فيها: طلب التأسيس / التوقيع الإلكتروني الخاص بالعميل + خدمات تانية |
| المنتجات | `#products` | 3 منتجات: **ESS** (فواتير + إيصالات إلكترونية) / **ERS** (إيصالات إلكترونية) / **ESA** (توقيع إلكتروني) |
| عن الشركة + العملاء | `#about` | نبذة عن الشركة + تجارب/قصص نجاح مع عملاء |
| شركاؤنا | `#partners` | فيكسد مصر (حلول رقمية وأمن معلوماتي) / توقيعي (ختم وتوقيع إلكتروني) / M.T.S (حلول تكنولوجية) — كل شريك لازم يكون له رابط يوصّل لموقعه |
| تواصل معنا | `#contact` | صفحة تواصل رئيسية |

> ملاحظة: هنبدأ بالـ Navbar (لازم يحتوي روابط لكل الصفحات دي حتى لو الصفحة نفسها لسه ملهاش محتوى) + Home + Footer.

## 2. الـ Navbar — مبني على هيكل Zapier

بناءً على تحليل Zapier:

- Header ثابت (fixed) بارتفاع ~70px، شفاف في الأول ويكتسب خلفية عند الـ scroll.
- **يسار:** لوجو DTS (من `public/images`).
- **وسط/يمين:** روابط الصفحات الرئيسية (الرئيسية / خدماتنا / المنتجات / عن الشركة / شركاؤنا / تواصل معنا).
  - المنتجات ممكن تاخد شكل **Mega Dropdown** بسيط (زي Products عند Zapier) يعرض الـ 3 منتجات (ESS / ERS / ESA) كل واحد بوصف سطر واحد + أيقونة.
- **أقصى اليمين:** زرار CTA (مثلاً "تواصل معنا" أو "اطلب عرض سعر").
- **موبايل:** Hamburger menu + Slide menu من الجانب مع overlay غامق، زي وصف Zapier بالظبط.
- **أنيميشن:** الخلفية تتحول بـ blur/background-color عند الـ scroll، الـ dropdown بـ fade + slide down.

## 3. صفحة الهوم — الأقسام (نسخة معدّلة، مبنية على هيكل Zapier، المحتوى DTS)

**تعديل مهم:** كل قسم في الهوم بيكون **مختصر جدًا** (highlights فقط) — لأن المحتوى التفصيلي الكامل بيكون موجود في صفحته المستقلة (خدماتنا / المنتجات / شركاؤنا... إلخ). الهوم دورها إنها "تعريفية" وتوجّه المستخدم للصفحة المناسبة، بالظبط زي Zapier.

التسلسل النهائي المتفق عليه:

1. **Hero Section**
   - عنوان كبير + وصف قصير + Badge صغير فوق العنوان + زرارين CTA (مثلاً "تواصل معنا" / "اكتشف منتجاتنا")
   - صورة/رسمة أو أنيميشن حي يمين (زي الـ hero illustration بتاع Zapier)

2. **Trust Bar (الشركاء)**
   - شريط لوجوهات — **الشركاء المهمين بس** (فيكسد مصر / توقيعي / M.T.S)، بيعمل scroll أفقي (marquee)، grayscale → color عند hover
   - قائمة الشركاء الكاملة تكون في صفحة `#partners` فقط

3. **قسم المنتجات (تابات، بديل "Toolkit tabs" عند Zapier)**
   - تابات أفقية للمنتجات التلاتة: ESS / ERS / ESA
   - كل تاب وصف مختصر جدًا (سطر أو اتنين) + صورة/رسمة + رابط "اعرف أكتر" يودي لصفحة المنتجات (المحتوى الكامل هناك)

4. **قسم الخدمات (Feature Grid مختصر)**
   - كروت مختصرة للخدمات الأساسية (أهمها طلب التأسيس/التوقيع الإلكتروني)، أيقونة + عنوان + سطر وصف، ورابط عام يودي لصفحة `#services` للتفاصيل

5. **إحصائيات + CTA (قسم واحد مدمج)**
   - أرقام تعبّر عن حجم/إنجازات الشركة (المحتوى هيتحدد لاحقًا) + عنوان CTA نهائي + زرار "تواصل معنا"

> **تم حذفها من الهوم** (هتتنقل بالكامل لصفحاتها المستقلة): قسم قصص النجاح/آراء العملاء الكامل (هيكون في `#about`)، قسم الـ Security التفصيلي، وقائمة الشركاء الكاملة (هتكون في `#partners`).

## 4. الفوتر — مبني على هيكل Zapier

- خلفية داكنة (نفس مود الموقع الأساسي).
- أعمدة متعددة:
  1. معلومات الشركة (لوجو صغير + وصف مختصر + روابط سوشيال ميديا)
  2. روابط المنتجات (ESS / ERS / ESA)
  3. روابط الشركة (عن الشركة / خدماتنا / شركاؤنا)
  4. تواصل (بريد إلكتروني / نموذج تواصل مختصر)
- **Bottom Bar:** حقوق الملكية © + روابط قانونية (سياسة الخصوصية...) لو موجودة.
